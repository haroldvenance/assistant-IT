# IT Support Assistant

Assistant intelligent pour le support informatique, basé sur les modèles de langage via l'API Groq.

## Fonctionnalités

- Chat interactif avec streaming des réponses
- Choix entre plusieurs modèles (Llama 3.1 8B, Llama 3.3 70B, DeepSeek-R1 Distill 70B)
- Gestion des conversations (création, renommage, suppression, recherche)
- Authentification sécurisée (JWT)
- Rôles utilisateur (normal / administrateur)
- Export des conversations (Markdown, HTML, PDF)
- Rate limiting (protection contre les abus)
- Résumé automatique du contexte pour les longues conversations
